Review file

Every keep, maybe, reject and reason you record becomes one line in an append-only event log. The log is kept in this browser; save it as a file to keep it, move it to another machine or hand it to someone else, and load a file to bring a review back.

Reviewer and bundle

Events carry the reviewer name, a time stamp, the learning switch and the bundle id. Put saved files in the bundle's reviews/ folder: nothing else needs to move. Files of several reviewers can be combined later because every event has its own id; this page shows one reviewer at a time and does not merge.
